# After Effects Scripts

### CompSizeAnchor.jsx
Изменяет размер активной композиции с выбором Anchor, как Canvas Size в Photoshop.

**Запуск:** открыть нужную композицию и сделать её активной.

### RemoveDublicates.jsx
Находит дубликаты выбранной папки и заменяет ссылки на их изображения ссылками на файлы из выбранной папки.

**Запуск:** выделить в Project panel папку, которую нужно оставить.

### ScaleEntireAEProject.jsx
Уменьшает все композиции и прекомпозиции проекта до 50% с сохранением их расположения.

**Запуск:** просто открыть нужный проект; выделять ничего не нужно.

Все скрипты запускаются через **File → Scripts → Run Script File…**
