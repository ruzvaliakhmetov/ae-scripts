# After Effects Scripts

### CompSizeAnchor.jsx
Changes the size of the active composition with an anchor selector, similar to Photoshop Canvas Size.

**Run from:** open the composition you want to resize and make it active.

### RemoveDublicates.jsx
Finds duplicate image folders and replaces links to duplicate footage with files from the selected folder.

**Run from:** select the folder in the Project panel that you want to keep.

### ScaleEntireAEProject.jsx
Scales all compositions and precompositions in the project to 50% while keeping their layout consistent.

**Run from:** just open the project; nothing needs to be selected.

Run all scripts via **File → Scripts → Run Script File…**
